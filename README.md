# VAuction

## Как пользоваться биржей

Откройте `/ah`. Главное меню сразу показывает покупку, продажу, ваши заявки, готовые получения, поиск и краткую помощь. `/market` и `/auction` — полные алиасы той же команды.

### Быстро продать

Возьмите предмет в основную руку и откройте `/ah`. Нажмите предмет в центре, затем «Продать сейчас». Биржа покажет, сколько готовы купить прямо сейчас, затрагиваемые цены, итог и минимальную цену исполнения. После подтверждения цена не опустится ниже показанной, а непроданный остаток не останется ждать покупателя.

Лимитную заявку можно создать командой:

```text
/ah sell 32 64
```

Это значит: продать 64 точных предмета из инвентаря по 32 монеты за штуку. Такая заявка останется ждать, если подходящего покупателя пока нет.

### Быстро купить

```text
/ah
→ Купить
→ товар
→ Купить сейчас
```

Перед подтверждением показываются ценовые уровни, итог, средняя и максимальная цена исполнения. Если рынок изменился, покупка не пройдёт дороже подтверждённого максимума; недоступный остаток не превращается в ожидающую заявку.

Лимитная команда:

```text
/ah buy minecraft:copper_ingot 64 32
```

Она создаёт заявку на 64 предмета максимум по 32 за штуку и может ждать продавца. Точные NBT-варианты выбираются через GUI.

### Проверить заявки и забрать покупки

```text
/ah orders
/ah claims
```

На странице заявок видно исполненное и оставшееся количество; активная карточка отменяется кликом. UUID вручную вводить не требуется — `/ah cancel` предлагает собственные заявки через Tab. Покупки и возвраты находятся на странице «Получить предметы».

После каждой части команды нажимайте Tab: доступны подсказки предметов, количеств, рыночных цен, собственных заявок и получений. `/ah help` содержит кликабельные примеры.

## Уведомления

Исполнения объединяются в одно сообщение за короткое окно, поэтому серия маленьких сделок не спамит чат и звуки. Онлайн-игрок видит купленное/проданное количество и остаток заявки. Если игрок был офлайн, при следующем входе показывается одна сводка только при наличии новых сделок или получений. Persistent cursor хранится в БД; повторный вход не повторяет уже показанную сводку.

## Безопасность торговли

- «Купить/Продать сейчас» использует marketable limit с ценой из подтверждённой котировки и семантикой partial IOC;
- котировка read-only: не резервирует деньги, не снимает предметы и не создаёт сделки;
- BUY исполняется только не дороже подтверждённого ceiling, SELL — только не дешевле floor;
- после bounded matching-прохода остаток закрывается существующим безопасным `cancel`;
- неиспользованный BUY-резерв освобождается штатной escrow-процедурой;
- непроданный SELL-остаток возвращается через существующие получения, без отдельной inventory-компенсации;
- durable IOC-маркер гарантирует закрытие остатка после crash/recovery;
- обычные лимитные заявки, matching, price/time priority, maker pricing и idempotency не изменены.

## Сервер и установка

VAuction — server-only мод для Minecraft Forge 1.20.1. GUI использует только ванильный `GENERIC_9x6`; custom Screen, MenuType, network channel и assets отсутствуют. VAuction и VEconomy клиенту не нужны.

- обязательная серверная зависимость: `economy_core` (VEconomy) 1.x;
- база: `<world>/vauction/auction.db` (SQLite);
- конфигурация: `<world>/serverconfig/vauction-server.toml`;
- V007 добавляет durable IOC-маркеры, компактный player notification cursor и targeted notification indexes;
- GUI-страницы ограничены 28 записями, стакан — 7+7 уровнями;
- notification flush и recovery имеют жёсткие лимиты работы.

Поместите production JAR VEconomy и VAuction с суффиксом `-all.jar` в серверную папку `mods/`.

## Сборка

```powershell
.\gradlew.bat clean test
.\gradlew.bat build
.\gradlew.bat jarJar
```

Итоговый артефакт с SQLite JDBC находится в `build/libs/VAuction-1.20.1-<version>-all.jar`.
