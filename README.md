# VAuction

VAuction — серверная биржа ресурсов для Minecraft Forge 1.20.1. Игрок открывает её командой `/market` (алиасы `/auction` и `/ah`) и работает через обычный ванильный сундук 9×6. Устанавливать VAuction или VEconomy на клиент не требуется.

## Как пользоваться

Введите `/market`, `/ah` или `/auction`: все три команды открывают одну и ту же биржу и имеют одинаковые подкоманды. В GUI можно выбрать точный предмет, включая его NBT, посмотреть предложения и создать заявку. Заявка может исполниться сразу, частично или ждать другого игрока.

- `/market help` — краткая справка с кликабельными заготовками команд;
- `/market search <название или id>` — поиск рынка;
- `/market info` — цены и точное количество предмета из основной руки;
- `/market sell <цена> [количество]` — продать точный предмет из основной руки. Если количество не указано, берутся все совпадающие предметы из всего инвентаря;
- `/market buy <предмет> <количество> <макс. цена>` — заявка на обычный предмет из реестра Minecraft. Вариант с особыми данными/NBT выбирайте через GUI;
- `/market orders` и `/market cancel <UUID>` — открыть свои заявки или отменить активную;
- `/market claims` и `/market claim <ID>` — открыть или забрать готовые получения.

После каждой части команды нажимайте Tab. Автодополнение предлагает подкоманды, идентификаторы предметов, полезные количества и цены, UUID собственных активных заявок и ID доступных получений. Цены в командах задаются в минимальных единицах валюты.

В GUI количество и цена настраиваются кнопками. Кнопки покупки и продажи создают лимитные заявки: покупка резервирует не больше указанной суммы, продажа забирает предметы только после подтверждения. На одном открытии GUI страницы меняются без повторного открытия контейнера, поэтому курсор не прыгает в центр.

Все клики проверяются сервером. Декоративные предметы нельзя забрать, переместить, выбросить, поменять горячей клавишей или собрать двойным кликом. Подтверждения BUY/SELL имеют долговечный ключ повторяемости: двойной клик не создаёт второй ордер, повторный резерв или повторное снятие предметов.

## Сервер

- обязательная зависимость: `economy_core` (VEconomy) версии 1.x;
- технический modId: только `vauction`;
- хранилище VAuction: `<world>/vauction/auction.db` (SQLite);
- конфигурация Forge для мира: `<world>/serverconfig/vauction-server.toml`;
- схема обновляется миграциями; V006 добавляет индексы ограниченных GUI-запросов;
- страницы содержат не более 28 записей, стакан — не более 7+7 уровней;
- обновление GUI выполняется по команде/клику, не каждый тик;
- торговые операции, escrow, отмены и доставки проходят через существующий `AuctionService` и восстановление после сбоев.

Для установки поместите серверные JAR VEconomy и VAuction в `mods/` сервера. Клиенту достаточно совместимого Forge-сборочного профиля сервера; эти два JAR на клиентской стороне не нужны.

## Сборка и проверка

```powershell
.\gradlew.bat clean test
.\gradlew.bat build
```

Итоговый серверный артефакт с SQLite-драйвером создаётся задачей `jarJar` в `build/libs/`; для установки используется файл с суффиксом `-all.jar`.
