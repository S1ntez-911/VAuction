# VAuction

Серверный аукцион предметов для Minecraft Forge 1.20.1. Расчёты выполняются через escrow API мода VEconomy; клиентская установка VAuction не требуется.

## Возможности

- перенесённый интерфейс TM2: точные слоты, материалы доступных в 1.20.1 кнопок,
  серые заполнители, карточки лотов, списки сортировки/категорий и окна подтверждения;
- сохранение полного NBT предметов;
- безопасная покупка с идемпотентным резервом VEconomy;
- восстанавливаемые квитанции выставления и выдачи защищают предметы при промежуточном сбое диска/SQLite;
- полная выплата цены продавцу без комиссии;
- лимит лотов и срок действия;
- архив отменённых, просроченных и не поместившихся в инвентарь предметов;
- уведомление продавца о продаже, в том числе после следующего входа;
- просмотр содержимого предметных и жидкостных контейнеров по ПКМ;
- сортировка (новые, старые, мои, дешёвые, дорогие), поиск и фильтр продавца;
- 16 понятных категорий TM2: инструменты, оружие, броня, еда, уникальное,
  зачарование, алхимия, зелья, блоки, декор, механизмы, ресурсы,
  растительность, добыча с мобов и разное;
- отдельные GUI моих лотов, архива, истории и подтверждения покупки/продажи/снятия;
- настраиваемые звуки продажи, покупки и действий;
- SQLite-хранилище в WAL-режиме с транзакциями и индексами;
- индексы в памяти по состоянию, продавцу и покупателю: просмотр и архив не перебирают всю историю.

## Команды

- `/ah` или `/auction` — открыть аукцион;
- `/ah help` — показать справку игроку;
- `/ah sell <цена> [количество]` — выставить предмет из основной руки;
- `/ah search <текст>` — найти товар по понятному названию;
- `/ah player <ник>` — открыть товары продавца;
- `/ah history` — открыть историю продаж;
- `/ah list` — показать свои активные лоты;
- `/ah cancel <id>` — снять свой лот;
- `/ah claim` — получить возвраты и незавершённые выдачи.

Административные команды: `/ah reload`, `/ah perf`, `/ah recover`. Они работают и из консоли;
`recover` повторно сверяет незавершённые покупки с escrow VEconomy без перезапуска сервера.

Цена вводится в отображаемых единицах VEconomy. Дробная часть (`10.50`, `10,50`) доступна,
если в конфиге VEconomy `decimalPlaces` больше нуля. Например, для цен `4.5` и `1.7`
нужно установить `decimalPlaces = 1` или `decimalPlaces = 2`.

## Сборка

По умолчанию проект использует API jar из `../VEconomy/build/libs/VEconomy-1.20.1-1.0.0.jar`.
Другую папку с этим jar можно передать свойством `-Pveconomy_dir=C:/path/to/libs`.

```powershell
.\gradlew.bat clean build
```

Готовый jar: `build/libs/VAuction-1.20.1-1.0.4.jar`. На сервере одновременно должен быть установлен VEconomy 1.0.0 или новее.

Все файлы VAuction находятся в `config/VMods/VAuction/`:

- `VAuction.toml` — механика, тексты GUI и ID предметов-кнопок;
- `lang/ru_ru.json` — локализация GUI, lore карточек и сообщений с цветовыми кодами `&`;
- `auction.db` — лоты, состояния покупок и очередь уведомлений.

Если рядом обнаружен старый `listings.json`, при первом запуске он транзакционно импортируется
в SQLite и переименовывается в `listings.json.migrated`. После этого JSON не используется.

Для изменения интерфейса jar пересобирать не нужно: отредактируйте `lang/ru_ru.json` и выполните
`/ah reload` от имени администратора. Многострочный lore задаётся через `\n`, цвета — кодами
`&0`–`&f`, `&l`, `&o`, `&n`, `&m`, `&k`, `&r`. Доступны подстановки `{price}`, `{seller}`,
`{item}`, `{remaining}`, `{page}`, `{pages}`, `{category}`, `{sort}` и другие, уже указанные в строках.
Механика, иконки категорий и все служебные предметы GUI настраиваются в `VAuction.toml`.
Также настраиваются срок лота, лимит лотов, срок хранения истории, минимальная и максимальная цена и список запрещённых предметов.
В секции `sounds` можно выключить звуки либо заменить их ID, громкость и высоту тона.

Автоматическую категорию нестандартного предмета можно переопределить в `categoryOverrides`:

```toml
categoryOverrides = [
  "create:wrench=TOOLS",
  "#forge:storage_blocks=GEMS",
  "create:mechanical_press=MECHANISMS"
]
```
Расположение 45 слотов и нижней панели остаётся фиксированным, поскольку GUI использует ванильный сундук и не требует клиентского мода.
Единственная материальная замена относительно TM2 — `OXIDIZED_COPPER_CHEST` заменён на бочку:
этого предмета нет в Minecraft 1.20.1, а ресурс-пак мод не требует.
