# VAuction

Универсальный серверный аукцион с фиксированной ценой для Minecraft Forge 1.20.1.
Для денег используется VEconomy (`economy_core` 1.x). Клиентам устанавливать VAuction
или VEconomy не требуется: интерфейс построен на обычном меню сундука.

## Команды игроков

- `/ah`, `/auction`, `/market` — открыть каталог;
- `/ah sell <цена>` — выставить одним лотом весь стек из основной руки;
- `/ah search <текст>` — открыть каталог с поиском;
- `/ah mine` — показать в каталоге только свои активные лоты;
- `/ah help` — краткая помощь.

Цена в `/ah sell` указывается за весь стек в формате валюты VEconomy. Поддерживаются
точка и запятая, например `1.40` и `1,40`. Нажатие на чужой лот открывает безопасное
подтверждение покупки. Нажатие на собственный лот снимает его с продажи. Купленные и
возвращённые предметы выдаются сразу, а при заполненном инвентаре остаются в кнопке
«Забрать предметы» главного каталога.

## Команды администратора

- `/ah reload` — перечитать интерфейс и правила категорий;
- `/ah admin category` — объяснить классификацию предмета в основной руке;
- `/ah admin recover` — вручную продолжить незавершённые безопасные операции.

Команды администратора требуют уровень доступа 2.

## Конфигурация

Все конфиги находятся в `config/VMods/VAuction/`:

- `vauction-server.toml` — лимиты, срок лота, комиссия и политика предметов;
- `auction-ui.json` — размер и оформление единственного настраиваемого экрана-каталога;
- `market-categories.json` — необязательные точечные переопределения автоматических категорий;
- `AUCTION-UI-README.txt` — справка по полям интерфейса и плейсхолдерам.

Экран подтверждения покупки намеренно фиксирован: его расположение нельзя случайно
сломать конфигом. Старую папку `ui/` от прежнего многоэкранного интерфейса мод при
первом запуске переносит в `ui-legacy-orderbook/` и больше не читает.

## Хранение и обновление

База находится в `<world>/vauction/auction.db` (SQLite). При обновлении со старой
биржевой версии активные заявки безопасно закрываются, деньги и предметы переходят в
штатный механизм возврата. Старые таблицы и recovery-код пока сохраняются исключительно
для этой миграции; создать старую заявку через команды или GUI уже нельзя.

## Сборка

```powershell
.\gradlew.bat clean build
```

Production JAR со встроенным SQLite JDBC создаётся в
`build/libs/VAuction-1.20.1-<version>.jar`. Файл с суффиксом `-slim.jar` для сервера
не предназначен.
